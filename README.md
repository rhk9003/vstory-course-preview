## A 版文字修改層

直接開啟 `version-a/?edit=1` 進入修改模式，或由 A 版右下角「提出文字修改」開啟。可框選同一段落中的部分文字，也可點選整段，再填入改稿與補充說明。原文保留，高亮標記與修改清單並存。

- 草稿使用 localStorage 保存在這台裝置的瀏覽器，沒有自動傳送或雲端同步。
- 「下載修改單」產生可閱讀的 HTML；「複製給 Dennis」產生純文字。使用者需自行傳送。
- 「下載備份／匯入備份」使用 JSON；匯入驗證原文位置與版本，保留既有草稿，衝突時整份拒絕，不部分覆蓋。
- 原文版本：`vstory-a-2026-10-07`。如果將來調整 A 版文案，需同步更新 revision 並處理舊稿遷移。
- `review-core.js` 是無 DOM 的驗證與匯出邏輯；`review.js` 是頁面互動；`review.css` 是獨立樣式。
- 本機測試：`node --test review-core.test.cjs`。
